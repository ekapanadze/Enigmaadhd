ENIGMA-ADHD: Brain Structure Differences

This reproduces case-control cortical thickness effect sizes from the ENIGMA-ADHD Working Group (Hoogman et al., 2017, Lancet Psychiatry), using publicly available summary statistics.

This project reproduces the core cortical thickness effect-size analysis from Hoogman et al. (2017, ENIGMA-ADHD) using their public summary statistics; the FDR correction, age-group comparison, and interactive visualizations are my own extensions.

Tools: Python (pandas, scipy/statsmodels for FDR correction, matplotlib, Plotly)

Hover over bars for exact values. Open in a new tab ->

Each bar shows Cohen's d for cortical thickness differences between ADHD patients and controls in adults. Positive values mean thicker cortex in ADHD; negative means thinner.

Data source: ENIGMA Toolbox (MICA-MNI). Analysis code and full pipeline: this repository.

Does age matter? Adult vs. adolescent ADHD

The chart above uses adult data only. But ENIGMA also has a separate adolescent cohort so I compared the two to see whether ADHD affects the same brain regions regardless of age, or whether the pattern shifts.

Hover over points for exact values. Open in a new tab ->

Each point is one brain region. If a region were affected identically in both age groups, it would sit on the red dashed line. Across all 68 regions, the correlation between adult and adolescent effect sizes is just r = 0.38 a weak relationship, suggesting the regions ADHD affects are not fixed, but shift with age.

The clearest example: bankssts (both hemispheres) shows almost no effect in adults (d is about 0.01) but a notable effect in adolescents (d = 0.16). The opposite pattern shows up in the parahippocampal region. Both flips appear on left and right sides independently, which makes them more likely to be a real pattern than noise.

Caveat: this compares two different groups of people (cross-sectional), not the same patients tracked over time so it shows that adult and adolescent ADHD populations differ structurally, not that any individual's brain changes this way as they age. Differences in scanner sites and sample sizes between cohorts could also contribute.

Does this survive correction for multiple comparisons?

Testing 68 brain regions at once inflates the chance of false positives. Only 2 of the 68 regions are nominally significant (p < 0.05) in adults before correction and after applying a Benjamini-Hochberg FDR correction, none survive at q < 0.05. Same story in adolescents: 4 regions nominal, 0 surviving FDR. This mirrors the original ENIGMA-ADHD finding: individual cortical effects are small and diffuse, which is precisely why consortium-scale sample sizes (thousands of scans) are needed to detect them reliably.
